# PDF 办公百宝箱 · GUI 手测清单（发布前验收）

每次发布前跑一遍。执行环境：Windows 10/11，`python -m pdf_gui`。

## 通用
- [ ] 窗口打开 1150×720，最小 980×640，左侧 9 个导航按钮（合并 … 图片转 PDF）
- [ ] 语言切换：所有界面文字变为英文/中文，当前面板参数保留（滑杆、单选、路径、输出目录）
- [ ] 关闭窗口后 `~/.pdf_office_toolkit.json` 更新（lang/out_dir/conflict/auto_open_out）
- [ ] 输出目录填一个不存在且不可写路径（如 `C:\Windows\x`）→ 弹「输出目录不可写」
- [ ] 左下角「配色」→ 改主色/背景色 → 保存后立即生效，重启仍生效
- [ ] 左下角「关于」→ 版本/仓库地址正确，仓库按钮能打开浏览器

## 文件队列（在合并面板验证）
- [ ] 添加文件/添加文件夹（文件夹含 PDF 时全部加入）
- [ ] **从资源管理器把 PDF 拖进窗口** → 加入队列；拖文件夹 → 展开其中 PDF
- [ ] **切到图片转 PDF 面板再拖 PDF** → 不接收（该面板只收图片）；拖图片 → 加入
- [ ] 上移/下移改变合并顺序
- [ ] 添加非 PDF（改后缀）→ 显示红色「无法读取」且不参与处理
- [ ] 添加加密 PDF → 弹密码框；密码错 → 红色条目；取消 → 同红色；密码对 → 「已解密（临时）」并参与处理

## 合并
- [ ] 全部合并为一个：2 个文件 → 1 个输出，页数相加，顺序与队列一致
- [ ] 按文件夹分别合并：两个文件夹的文件 → 2 个输出
- [ ] 同名规则三种行为：自动重命名 → `(1)` 后缀；覆盖 → 内容被替换；跳过 → 报告计入「跳过」

## 拆分
- [ ] 每 N 页：10 页拆 3 → 4 份（3+3+3+1）
- [ ] 按范围 `1-3,5` → 2 份；非法范围 → 报告失败项显示 core 错误
- [ ] 按空白页分段：含空白页 PDF 正确分段
- [ ] N 填非数字 → 弹错误提示，不崩溃

## 水印
- [ ] 文字水印：中文正常渲染（STSong），平铺 45°、不透明度、字号生效
- [ ] 单个居中模式
- [ ] 页码过滤：`2` 只打第 2 页；`99` 报告失败
- [ ] 图片水印：位置 9 选 1、大小比例、不透明度生效

## 盖章
- [ ] 预览图显示文件第 1 页 + 印章
- [ ] 点击预览定位：点页面上部印章去页顶（y 语义正确）
- [ ] 大小/不透明度滑杆实时反映；输出与预览一致

## 骑缝章
- [ ] 预览显示第 1 页与最后一页；最大条数/高度调整后预览更新
- [ ] 输出打印拼合后还原完整印章

## 加密解密
- [ ] 加密输出打开需密码；解密后可直接处理
- [ ] 密码框不回显明文

## 压缩
- [ ] 无损：页数不变；光栅化 72DPI：体积明显变小

## 转图片
- [ ] PNG/JPG、DPI、质量；子目录命名 `{stem}_{fmt}`
- [ ] 跳过/覆盖行为

## 图片转 PDF
- [ ] 多张图片按队列顺序合成一份；A4 页面方向随图片自动横/竖
- [ ] 原始尺寸：页面大小 = 图片像素 ÷ DPI
- [ ] 页边距生效，图片等比缩放居中，不拉伸
- [ ] 透明 PNG 输出白底，不是黑底
- [ ] 输出文件名不带 `.pdf` 时自动补上

## 取消与报告
- [ ] 长任务（转图片多文件 / 压缩光栅化）运行中点「取消」→ 尽快停在当前页，剩余任务计入「跳过」，报告弹窗正常
- [ ] 取消后不留半截输出文件
- [ ] 报告弹窗：✓ 成功 / ✗ 失败含错误信息 / ⊘ 跳过与取消，底部三个计数
- [ ] 报告弹窗「打开输出目录」按钮能打开目录

## 完成后打开输出目录
- [ ] 运行条勾选后跑一次成功的任务 → 结束后自动打开输出目录
- [ ] 勾选状态在切换面板、重启后保持一致
- [ ] 任务全部失败或取消时**不**自动打开
